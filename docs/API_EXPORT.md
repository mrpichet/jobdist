# JobDist API export

> Generated by `tools/JobDist.ApiExport` from the compiled assemblies and XML doc comments. Do not edit by hand:
> run `dotnet run --project tools/JobDist.ApiExport -- docs` after changing the API. Machine-readable copy: `api-export.json`.

JobDist is a distributed job scheduler. The same business logic is served as a **REST API** (`/api/*`) and as an **MCP server** (`/mcp`, tools built with Microsoft.Extensions.AI).

## Authentication

- Every call: header `X-Api-Key: <key>`. Keys map to roles **Admin, Submitter, Viewer, Worker, AiAgent** (only SHA-256 hashes are stored server-side).
- Worker calls (`/api/workers/{workerId}/...`): also `X-Worker-Token: <token>` returned once by `POST /api/workers/register`.
- Enums are serialized as strings (e.g. `"Pending"`). Times are ISO-8601 UTC. Errors are RFC 7807 problem details.
- Policies: Read = Viewer/Submitter/Admin, Submit = Submitter/Admin, Admin = Admin, Worker = Worker, AiAgent = AiAgent/Admin.

## MCP / AI tools

Endpoint `POST /mcp` (Streamable HTTP, stateless), API key with role **AiAgent**; or the stdio host `src/JobDist.McpServer`.
Side-effect tools are only listed when the server sets `Mcp:AllowSideEffects=true`.

### `assess_job_risk`

Calculate the risk (0-100) that a job fails, is delayed or is lost: no capable/online worker, strict target offline, backlog vs capacity, historical failure rate, expected duration vs timeout, attempts already used, unstable assigned worker. Returns score, level, factors and a recommendation.

| Parameter | Type | Required | Description |
|---|---|---|---|
| `jobId` | string | yes | Job id (GUID). |

### `assess_submission_risk`

What-if: calculate the risk (0-100) of submitting a job of the given type BEFORE creating it (capability, redundancy, backlog, history, timeout, encryption keys for sensitive payloads). Nothing is created.

| Parameter | Type | Required | Description |
|---|---|---|---|
| `jobType` | string | yes | Job type, e.g. 'image.resize'. |
| `targetWorkerId` | ["string","null"] | no | Optional worker id (GUID) that should run the job. |
| `strictTarget` | boolean | no | true = run only on targetWorkerId. |
| `timeoutSeconds` | ["integer","null"] | no | Timeout per attempt in seconds (null = server default). |
| `sensitive` | boolean | no | true when the payload is confidential (needs encrypted delivery). |

### `assess_worker_risk`

Calculate the health risk (0-100) of a worker: availability, network instability (offline count), learned failure rate per job type, CPU/memory pressure and missing post-quantum keys.

| Parameter | Type | Required | Description |
|---|---|---|---|
| `workerId` | string | yes | Worker id (GUID). |

### `detect_anomalies`

Detect abnormal job distribution in a recent window: submission spikes (z-score), high failure rates per job type or worker, slow execution, flapping workers, fail-over storms, queues without capable workers and suspicious worker reports.

| Parameter | Type | Required | Description |
|---|---|---|---|
| `windowMinutes` | integer | no | Window size in minutes (5-1440). |

### `recommend_workers`

| Parameter | Type | Required | Description |

| `top` | integer | no | Max results (1-100). |

## SDKs

- **Submit jobs** from another project: reference `JobDist.Client`, `services.AddJobDistClient(configuration.GetSection("JobDistClient"))`, inject `IJobDistClient`.

| `ExecuteAsync(JobContext context, CancellationToken ct)` | Task<JobResult> | Executes one job. |
| `JobType` | string | Job type this handler runs (e.g. `image.resize`). Must be unique per worker. |
| `MaxConcurrency` | int | Maximum parallel executions of this type on this worker (advertised to the server). |
| `SpeedFactor` | double | Self-declared relative speed (1.0 = baseline). The server's ML model learns the real value from history. |

### `JobContext` (record)

Information about the job being executed.

| Member | Type | Description |
|---|---|---|
| `JobId` | Guid | Job id. |
| `AttemptId` | Guid | Attempt id (unique per distribution). |
| `JobType` | string | Job type. |
| `Attempt` | int | 1-based attempt number (greater than 1 means this is a retry: make the handler idempotent). |
| `Priority` | int | Priority 0-100. |
| `Timeout` | TimeSpan | Execution timeout given by the server. |
| `Payload` | string | Decrypted payload (usually JSON), or null. |
| `WasEncrypted` | bool | True when the payload arrived as a post-quantum hybrid envelope. |

### `JobResult` (record)

Outcome of a handler.

| Member | Type | Description |
|---|---|---|
| `Success` | bool | True when the job succeeded. |
| `Output` | string | Optional output text / JSON (max 1 MB). |
| `Error` | string | Error text on failure (max 4,000 chars; never include secrets). |
| `Retryable` | bool | Whether a failure may be retried on another attempt. |

### `JobDistWorkerOptions` (class)

Worker settings (section `JobDistWorker`).

| Member | Type | Description |
|---|---|---|
| `ServerUrls` | List<string> | All server instances (HA). The worker fails over between them on network errors and 5xx. |
| `ApiKey` | string | API key with the `Worker` role (inject through a secret store or environment variable). |
| `WorkerName` | string | Unique worker name. Defaults to the machine name. Re-using the name after a crash re-uses the worker id. |
| `MaxTotalConcurrency` | int | Total parallel jobs across all types. Defaults to the number of logical CPU cores. |
| `ConcurrencyOverrides` | Dictionary<string, int> | Per-type concurrency overrides (job type → max concurrency), take precedence over the handler default. |
| `BenchmarkScore` | double | Relative machine benchmark (1.0 = baseline). 0 = measure automatically at start-up. |
| `GpuCount` | int | Number of GPUs available to jobs. |
| `Tags` | List<string> | Labels such as `zone=a`. |
| `PollWaitSeconds` | int | Long-poll wait in seconds (0-30). |
| `RequireSignatures` | bool | Reject assignments and commands whose server signature does not verify (strongly recommended). |
| `PinnedServerKeyId` | string | Optional pin of the server signing key id. When set, keys with another id are rejected and never refreshed automatically (protects against a malicious server that tries to rotate in its own key). |
| `RequestTimeout` | TimeSpan | HTTP timeout for normal (non long-poll) calls. |
| `ReportRetention` | TimeSpan | How long a completion report is retried while the server is unreachable before it is dropped. |
| `UnregisterOnShutdown` | bool | Unregister from the server on graceful shutdown (running jobs are re-distributed immediately). |
| `ShutdownGracePeriod` | TimeSpan | Time given to running jobs to finish during shutdown before they are cancelled. |
